## 项目核心内容与神学架构

1. **原文一字不差权威来源**  
   - 本站收录的《海德堡要理问答》全部 **52 个主日（1–129 问）**、**三大普世信经**（《使徒信经》《尼西亚信经》《亚他那修信经》）以及《比利时信条》《多特信经》简介与引用，均**一字不差**采自 [基督教华人网络团契 (https://ccifellowship.org)](https://ccifellowship.org)。
2. **先宏观、后微观的神学纵深**  
   - **整本圣经与圣约神学流程图**：从永恒救赎之约、行为之约与堕落，到创 3:15 原始福音、亚伯拉罕/西奈/大卫之约、基督新约成全与终末新天新地，对照《罗马书》“罪苦—得救—感恩”三部曲。
   - **真实历史时间线、故事线与地理文化地图**：D3 + TopoJSON 矢量互动地图呈现海德堡、多特、安特卫普、日内瓦、苏黎世、维滕贝格、威斯敏斯特、罗马、尼西亚、君士坦丁堡、亚历山大 11 座信仰地标，详述帕拉丁选侯国、腓特烈三世、乌尔西努与奥利维亚努的历史故事。
   - **欧陆改革宗六大信仰标准思维导图**：清晰联结三大普世信经、三项联合信条与长老会威斯敏斯特三大信仰准则。
3. **全部 52 个主日六维深度剖析**  
   - 涵盖：本质核心与欧陆改革宗剖析、真实历史背景与护教情境、圣经神学纵深、圣约神学视角、三项联合信条/普世信经/威敏呼应、当代门徒实践应用，并配有一句话速记口诀、重点高亮、护教难点辨析、语音朗读、答案遮罩背诵与掌握进度记录。
4. **三大普世信经干净阅读背诵殿堂 & 深度对比**  
   - 提供无干扰干净排版、字号调节、关键词填空遮罩背诵、语音朗读、一键复制；以及三份信经多维对比表与“为何教会需要三份信经而不是一份”专题剖析。
5. **快速记忆实验室与现代化响应式 UI**  
   - 52 主日翻转闪卡、一图速记总表、8 题正统神学互动自测；100% 平铺自适应手机/平板/电脑、毛玻璃视觉风格、深浅色主题切换与可隐藏全景目录（快捷键 `[`）。
